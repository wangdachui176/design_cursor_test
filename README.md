# 联想开放平台首页 - HTML Demo

根据 Figma 设计稿还原的联想开放平台首页，纯静态 HTML / CSS / 原生 JS，无构建依赖。

## 预览

直接用浏览器打开 `index.html`，或启动本地服务：

```bash
python -m http.server 4173
```

然后访问 http://127.0.0.1:4173

## 页面结构

| 分区 | 高度 |
|---|---|
| 顶栏 + 主导航 | 38 + 64 |
| 主视觉 Banner | 496 |
| 公告栏 | 80 |
| 数据概览（两张指标卡） | 589 |
| 智能体生态（含标签切换栏） | 710 |
| 全生命周期应用服务 | 642 |
| 商业增长与合作 | 586 |
| 注册 CTA | 249 |
| 页脚 | 303 |
| 合计 | 3757 |

设计基准为 1920px 画布，内容容器 1200px，整页高度与设计稿一致。

## 交互

- 主导航「应用发布」悬停展开整宽下拉面板（4 列 × 2 行分组 + 底部公告栏）
- 下拉面板支持移入不收起、`Esc` 关闭、点击外部关闭、触摸设备点击切换
- 站内搜索框聚焦与默认提示

## 资源说明

页面引用的素材均由 Figma 导出，位于 `assets/figma/`。
设计稿比对用的整页参考图与早期重复导出的素材已通过 `.gitignore` 排除，不会进入仓库。

## 说明与已知差异

- Banner 与智能体区的插画为整图导出，无法拆成独立图层
- 卡片背景的模糊光斑以 CSS 近似还原
- 依赖 Microsoft YaHei 字体，未安装时会回退到系统字体
- 部分图标（通知铃铛、语言箭头、搜索放大镜）为 SVG 手绘近似
