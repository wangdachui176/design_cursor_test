# 设计 Token 说明

以下 Token 与 Figma「基础变量」集合对应，项目内通过 `figma-variables-resolver.js` 与 `theme.js` 使用。

## 颜色 (COLOR)

| Token 名称 | 值 | 说明 |
|-----------|-----|------|
| 颜色/黑 | `#000000` | 主文字、主按钮背景 |
| 颜色/白 | `#FFFFFF` | 背景、按钮文字 |
| 颜色/浅黑 | `#333333` | 次要文字、Button_A hover 背景 |
| 颜色/浅灰 | `#666666` | 副标题、说明文字 |
| 颜色/灰 | `#999999` | 占位符等 |
| 颜色/白蓝 | `#F5F7F9` | 列表卡片背景、Button2 背景 |
| 颜色/浅白蓝 | `#EFF1F6` | 列表 hover、Button2 hover |

## 字体与字号 (STRING / FLOAT)

| Token 名称 | 值 | 说明 |
|-----------|-----|------|
| 文本/字体/常规 | `Microsoft YaHei` | 全局正文字体 |
| 文本/字重/默认 | `Regular` | 400 |
| 文本/字重/加粗 | `Bold` | 700 |
| 文本/字号/1级正文 | `14` | 输入框、搜索文本、列表标题 |
| 文本/字号/2级正文 | `12` | 列表副标题、按钮文字 |
| 文本/字号/3级正文 | `10` | 小号按钮（如 AI搜索） |

行高：正文约 `1.32`，标题约 `1.33`（相对字号）。

## 圆角 (FLOAT, px)

| Token 名称 | 值 |
|-----------|-----|
| 圆角/6 | 6 |
| 圆角/8 | 8 |
| 圆角/16 | 16 |
| 圆角/100 | 100（胶囊按钮） |

## 间距 (FLOAT, px)

| Token 名称 | 值 |
|-----------|-----|
| 间距/4 | 4 |
| 间距/6 | 6 |
| 间距/8 | 8 |
| 间距/12 | 12 |
| 间距/14 | 14 |

## 大小 (FLOAT, px)

用于图标、固定尺寸等。

| Token 名称 | 值 |
|-----------|-----|
| 大小/12 | 12 |
| 大小/14 | 14（图标 14×14） |
| 大小/18 | 18 |
| 大小/20 | 20 |
| 大小/30 | 30（列表图标 30×30） |

## 描边 (FLOAT, px)

| Token 名称 | 值 |
|-----------|-----|
| 描边/1 | 1 |
| 描边/2 | 2 |

## 效果

- **阴影**：`0px 2px 20px 0px rgba(0, 0, 0, 0.04)`（搜索框）
- **边框渐变（AI 渐变色）**：`linear-gradient(130deg, rgba(58, 167, 255, 1) 1%, rgba(150, 110, 255, 1) 49%, rgba(255, 149, 132, 1) 99%)`，130deg，1px 描边。
